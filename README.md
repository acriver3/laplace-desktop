# Laplace Desktop (discontinued)

Laplace has ended releases of the Desktop app and its device-local runtime. Existing signed installers, tags and the signed update index remain available for people who already have the app.

Use [Laplace Connect](https://connect.withlaplace.com) for hosted connections and [the migration guide](https://withlaplace.com/docs#migrate-local-library-connectors-to-the-laplace-extension) to move supported browser workflows. The source at each released tag documents that version.
